# Photos and videos

Gallery photos and short walk videos live in this folder. `favicon.svg` is the small icon on the browser tab.

Photos on the site are saved as JPEGs about 1200 pixels wide. Videos are short, muted files that play inline and show controls.

To swap a picture, replace the file or point `src` in `index.html` at a new file in this folder, and update the `alt` text so it describes that photo.
